How to tinker

1. Hear something immediately. Click a flagship on the left, then Render. bach_meets_vangelis is the morphing FM brass weave.

2. Change the music, not the engine. Edit the chord string. Syntax: Cm9 -> Abmaj9#11, slash bass Cmaj9/E, length Cm9*8, raw Hz [220, 275, 330].

3. Swap the weave. Cthulhu = arpeggio + pad. Bach = 16ths. Cathedral = pads. Stranger = 80s pulse. 3v4 = Glass. Counterpoint = four gliding voices.

4. Type physics. Variables: t f w env mod_idx lfo1 phi. Functions: fm(fc,fm,idx,t) fm3(...) cheb(n,x) harm(w,n,r) bell(...) ks(f,t,damp).

5. Microtone. Just Intonation locks 5:4 / 3:2. edo31 is 31 equal steps. Werckmeister is historical keyboard temperament.

6. DX7. Set algorithm 1–32 (Yamaha public routing tables). 0 = keep the Harmonia patch graph.

CLI twin: harmonia serve --port 8765 · harmonia chord "…" · harmonia math "…"
